Kimi(Moonshot) API 잔액 확인 방법

Kimi는 잔액 전용 API를 공식 문서로 제공합니다. 다만 잔액이 세 가지로 쪼개져 오기 때문에 어느 값을 봐야 하는지가 갈립니다. (2026-08 기준)

방법 1 — 콘솔에서 확인

platform.kimi.ai에 로그인하면 잔액이 표시됩니다. 충전 내역과 사용 내역도 같은 화면에서 볼 수 있습니다.

방법 2 — API로 직접 조회

curl "https://api.moonshot.ai/v1/users/me/balance" \
  -H "Authorization: Bearer $KIMI_API_KEY"

응답은 이렇게 옵니다.

{
  "code": 0,
  "data": {
    "available_balance": 49.58894,
    "voucher_balance": 46.58893,
    "cash_balance": 3.00001
  },
  "status": true
}

세 가지 잔액 필드의 차이 (중요)

여기서 실수하기 쉽습니다. 봐야 할 값은 available_balance입니다.

  • cash_balance — 실제로 충전한 금액입니다. 음수가 될 수 있습니다(사용분이 충전분을 넘어선 경우).
  • voucher_balance — 프로모션·쿠폰으로 받은 크레딧입니다.
  • available_balance — 위 둘을 합쳐 실제로 호출에 쓸 수 있는 금액입니다. 이 값이 0 이하가 되면 Moonshot이 API 호출을 거부합니다.

바우처가 남아 정상적으로 호출되는 계정인데도 cash_balance는 마이너스일 수 있습니다. 그래서 cash_balance만 읽으면 멀쩡한 계정을 "잔액 부족"으로 오판하게 되고, 두 값을 단순히 더하면 실제보다 많게 나옵니다.

함정 — .ai 키와 .com 키는 호환되지 않습니다

platform.kimi.ai와 platform.kimi.com은 완전히 별개의 계정 체계입니다. 한쪽에서 발급한 키로 다른 쪽 호스트를 호출하면 401이 떨어집니다.

이 오류가 "키가 잘못됨"으로 읽히기 때문에, 키를 몇 번씩 재발급하며 헤매기 쉽습니다. 키를 어느 콘솔에서 받았는지 먼저 확인하고 그에 맞는 API 호스트를 쓰세요.

방법 3 — 대시보드에서 다른 서비스와 한 번에

SubscribeInventory에서 한 화면으로 → Kimi 잔액과 함께 OpenAI·Claude·xAI·ElevenLabs 등 10개 서비스의 잔액·사용량을 무료로 한 번에 확인하고, Slack 잔여량 알림까지 받을 수 있습니다. 키는 브라우저에만 저장됩니다.

자주 묻는 질문

특별한 키가 필요한가요?

아니요, 일반 API 키면 됩니다. 관리자 전용 키를 따로 발급할 필요가 없습니다.

어느 필드를 잔액으로 봐야 하나요?

available_balance입니다. 이 값이 0 이하면 호출이 막힙니다.

401이 나는데 키는 맞습니다.

키를 발급한 콘솔(.ai / .com)과 호출하는 호스트가 다른 경우입니다.
