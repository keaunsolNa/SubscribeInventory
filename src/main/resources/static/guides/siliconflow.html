SiliconFlow(실리콘플로우) 잔액 확인 방법

SiliconFlow는 잔액 조회 API를 공식 문서로 제공합니다. 다만 응답에 통화 단위가 들어 있지 않아 사이트를 구분해야 합니다. (2026-08 기준)

방법 1 — 콘솔에서 확인

중국 사이트는 cloud.siliconflow.cn, 글로벌 사이트는 cloud.siliconflow.com에 로그인하면 잔액이 표시됩니다. 가입은 휴대폰 인증만으로 가능하고 카드 등록이 필요 없습니다.

방법 2 — API로 직접 조회

curl "https://api.siliconflow.com/v1/user/info" \
  -H "Authorization: Bearer $SILICONFLOW_API_KEY"

중국 사이트 계정이라면 호스트를 api.siliconflow.cn으로 바꿔 호출합니다. 응답은 이렇게 옵니다.

{
  "code": 20000,
  "status": true,
  "data": {
    "id": "...",
    "name": "...",
    "balance": "0.88",
    "chargeBalance": "88.00",
    "totalBalance": "88.88"
  }
}

세 가지 잔액 필드의 차이

  • balance — 가입·이벤트로 받은 증정 크레딧입니다.
  • chargeBalance — 직접 충전한 금액입니다.
  • totalBalance — 위 둘을 합친 실제 사용 가능액입니다.

주의할 점이 하나 더 있습니다 — 값이 숫자가 아니라 문자열로 옵니다 ("88.88"). 그대로 계산에 넣으면 문자열 연결이 되거나 타입 오류가 납니다.

함정 — .cn과 .com은 통화가 다릅니다

응답 어디에도 통화 필드가 없는데, 두 사이트는 서로 다른 화폐로 청구합니다.

  • siliconflow.cn (중국 사이트) — CNY(위안)
  • siliconflow.com (글로벌 사이트) — USD(달러)

두 사이트는 계정 자체가 분리되어 있어 키도 호환되지 않습니다. 여러 서비스의 지출을 합산하는 용도라면 이 구분을 놓칠 경우 위안화 금액이 달러 합계에 그대로 더해져 총액이 틀어집니다. 응답만 봐서는 알 수 없으므로 키를 발급한 사이트로 판단해야 합니다.

방법 3 — 대시보드에서 다른 서비스와 한 번에

SubscribeInventory에서 한 화면으로 → SiliconFlow 잔액과 함께 OpenAI·Claude·xAI·ElevenLabs 등 10개 서비스의 잔액·사용량을 무료로 한 번에 확인하고, Slack 잔여량 알림까지 받을 수 있습니다. 키는 브라우저에만 저장됩니다.

자주 묻는 질문

특별한 키가 필요한가요?

아니요, 일반 API 키면 됩니다.

어느 필드를 잔액으로 봐야 하나요?

totalBalance입니다. 문자열로 오니 숫자로 변환해서 쓰세요.

통화가 위안인지 달러인지 어떻게 아나요?

응답에는 없습니다. 키를 발급한 사이트가 .cn이면 CNY, .com이면 USD입니다.
