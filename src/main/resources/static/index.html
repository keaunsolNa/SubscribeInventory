구독 서비스 대시보드

AI 구독형 서비스의 잔여 할당량 · 크레딧 · 이번 달 사용액을 한눈에 준비됨

🔑 내 API 키 (BYOK — 이 브라우저에만 저장)
키는 이 브라우저(localStorage)에만 저장됩니다. 조회할 때마다 요청에 실려 백엔드가 각 서비스로 중계만 하며, 서버에는 저장·로깅되지 않습니다. 비워두면 서버에 환경변수로 설정된 키(있다면)를 사용합니다.
🔔 Slack 알림 구독 (잔여량 경고)
구독하면 위 "내 API 키" 패널의 키와 Webhook URL이 서버에 암호화되어 저장되고(옵트인), 매시 정각 서버가 잔여량을 점검해 임계값 초과 시 입력한 Slack 채널로 알립니다. 구독 시 확인 메시지가 채널로 1회 발송되고, 같은 Webhook으로 다시 구독하면 설정이 갱신됩니다. 같은 경고 상태는 반복 발송하지 않으며, 해지하면 저장된 정보가 즉시 삭제됩니다.

SubscribeInventory는 어떤 서비스인가요?

여러 AI 구독형 서비스의 잔여 크레딧, 할당량, 이번 달 사용액을 한 화면에서 확인하는 무료 대시보드입니다. 잔여량이 설정한 임계값 아래로 내려가면 Slack으로 알림을 보냅니다.

어떤 AI 서비스를 지원하나요?

ElevenLabs, xAI(Grok), OpenAI, Anthropic(Claude), DeepSeek, OpenRouter, Stability AI, fal.ai, Kimi(Moonshot), SiliconFlow — 총 10개 서비스의 잔여 크레딧 또는 사용액 조회를 지원합니다.

API 키는 안전하게 관리되나요?

BYOK(Bring Your Own Key) 방식입니다. 키는 사용자의 브라우저(localStorage)에만 저장되고, 서버는 조회 요청을 각 서비스로 중계만 할 뿐 키를 저장하거나 로깅하지 않습니다. Slack 알림 구독 시에만 키가 AES-256-GCM으로 암호화되어 저장됩니다.

Slack 잔여량 알림은 어떻게 받나요?

대시보드의 Slack 알림 구독 패널에서 Slack Incoming Webhook 주소와 임계값을 등록하면, 매시 정각에 자동 점검해 잔여 크레딧이 임계값 이하로 내려갔을 때 해당 채널로 경고를 보냅니다.

이용 요금이 있나요?

무료입니다. Google 계정으로 로그인한 뒤 본인의 API 키를 등록해 바로 사용할 수 있습니다.
